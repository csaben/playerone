player-one

Pick any window from the keyboard and attach an AI to it. The agent is a hello-world typing macro for now.

  1. CtrlAltA opens the panel on the window you were in
  2. jk move, Enter attaches: the panel closes and it types hello world
  3. Reopen: Notepad sits under Attached
  4. / searches by app or title; Enter on a match attaches again
